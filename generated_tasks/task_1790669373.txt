```plaintext
def fibonacci(n):
    if n < 0:
        raise ValueError("Input must be a non-negative integer.")
    elif n == 0:
        return 0
    elif n == 1:
        return 1

    a, b = 0, 1
    for _ in range(2, n + 1):
        a, b = b, a + b
    return b

if __name__ == "__main__":
    print("--- Fibonacci Sequence Examples ---")
    for i in range(11):
        print(f"F({i}) = {fibonacci(i)}")
```

This script defines a function `fibonacci` that calculates the n-th Fibonacci number using an iterative approach. It includes error handling for negative inputs and demonstrates the function's usage by printing the first 11 Fibonacci numbers.
